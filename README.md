# MobiAtelier

**모비 아틀리에**는 마비노기 모바일 캐릭터의 외형과 의상, 염색 조합을 미리 확인하기 위한 Unity 기반 Windows용 꾸미기 도구입니다. 게임에서 외형을 변경하거나 의상을 구매·염색하기 전에 원하는 코디를 살펴볼 수 있도록 만드는 것을 목표로 합니다.

사용자 PC에 설치된 마비노기 모바일의 패치파일을 읽어 모델과 텍스처를 불러오고, 캐릭터를 런타임에 조립하는 방식으로 개발합니다. 게임 리소스는 프로그램에 포함하지 않으며, 이용하려면 마비노기 모바일 PC 클라이언트가 설치되어 있어야 합니다.

## 개발 목표

- 얼굴·피부색·헤어·체형 등 캐릭터 외형 설정
- 부위별 의상과 액세서리 착용·교체
- 헤어 및 의상 부위별 염색 미리보기
- 캐릭터 회전·거리·화각 조절과 코디 내보내기·가져오기

현재 초기 개발 단계이며, 위 기능을 순차적으로 구현할 예정입니다.
