# 이전 종료 팝업 기획의 대체 안내

> 정리일: 2026-11-03

2026-11-03 사용자 결정으로 기존 `ESC → 종료 확인 팝업` 기획을 폐기하고 시스템 메뉴로 대체했다.

- 기본 ESC: 시스템 메뉴 열기.
- 시스템 메뉴에서 ESC: 메뉴 닫기.
- 메뉴의 종료: 대기 중 작업 저장 성공 후 종료. 추가 종료 확인 팝업은 띄우지 않는다.
- 초기화 확인·저장 실패·부분 복원 안내는 각각의 용도로 유지한다.
- 열린 하위 UI의 ESC 우선순위와 창 닫기 요청은 새 기획을 따른다.

현재 기준은 [시스템 메뉴·종료·ESC](SystemMenu.md)다. 이 파일은 이전 링크를 위한 안내이며 별도 구현 대상이 아니다.
