# 옵션·설치 경로 변경 기획

> 정리일: 2026-11-03
> 사용자 결정: 시스템 메뉴의 옵션에서 게임 설치 경로를 바꾸고, 적용 후 재시작해 반영한다.
> 현재 필수 옵션은 게임 경로다. 나머지 항목은 확장 후보이며 구현 완료가 아니다.

## 1. 진입과 화면

- 시스템 메뉴 → 옵션으로 진입한다. 경로 검사 팝업과 같은 검사 기준·폴더 선택 기능을 재사용한다.
- 현재 정상 게임 경로를 입력란에 표시하고 폴더 선택 버튼을 제공한다.
- 주요 버튼은 `적용 후 다시 시작`·`돌아가기`다. 경로 변경에 재시작이 필요함을 버튼에서 알 수 있게 한다.
- 입력란·검사 결과·버튼은 앱 표시 영역 안으로 보정한다. 뒤의 카메라·꾸미기 입력은 차단한다.
- 입력 중인 경로와 마지막 정상 경로는 분리한다. 입력만 하거나 돌아가기·ESC로 닫은 경로는 적용하지 않는다.
- 정상화한 경로가 기존과 같으면 불필요한 재시작을 하지 않는다. 적용 버튼을 비활성화하는 것을 제안한다.

## 2. 적용 순서

1. 입력 경로를 정상화하고 폴더·필수 index·데이터·읽기·시트 해석을 검사한다(Startup.md).
2. 실패하면 원인을 입력란 아래 표시한다. 기존 경로·실행·작업·이력을 유지한다.
3. 성공하면 현재 확정 작업과 대기 중 자동 저장을 저장한다. 저장 실패 시 재시작·경로 교체를 보류한다.
4. 새 정상 경로를 앱 설정에 기록한다. 기록 실패 시 현재 실행을 유지하고 재시도를 안내한다.
5. 재시작을 진행한다. 새 실행은 새 경로를 검사하고 마지막 작업을 복원한다.
6. 재시작 실패 시 기존 정상 설정·작업을 복구할 수 있게 한다. 재시작이 성공한 것처럼 안내하고 작업을 버리지 않는다.

검사 중 적용 버튼 중복 입력을 막는다. 게임 설치 폴더는 읽기만 한다. 새 설치본에 없는 ID·제한된 항목은 기존 부분 복원 정책을 따른다.

## 3. 사용자 안내

입력란 가까이에 다음 내용을 표시한다.

> 경로 변경은 다시 시작한 뒤 적용됩니다. 현재 작업은 저장 후 복원되며, 실행 취소·다시 실행 이력은 초기화됩니다.

- 일반 옵션 창을 여닫는 것만으로 재시작하거나 이력을 지우지 않는다.
- 게임 경로는 앱 환경 설정이다. 사용자 코디 JSON·꾸미기 이력에 넣지 않는다.
- 재시작 뒤에는 꾸미기 패널을 닫은 기본 UI로 시작하고, 저장된 장면·카메라와 패널 크기·펼침 설정을 복원한다.

## 4. 확장 후보

| 후보 | 용도 | 상태 |
|---|---|---|
| 회전·화면 이동·휠 감도 | 입력 장치와 사용 습관에 맞춘 카메라 조절 | 후속 후보 |
| 휠 방향 반전 | 거리 조절 방향 선택 | 후속 후보 |
| UI·글자 크기 | 해상도·가독성 대응 | 후속 후보 |
| 빠른 조작 안내 표시 | 익숙해진 뒤 하단 안내 접기 | 후속 후보 |

이 후보들을 이번에 필수 구현·설정값으로 확정하지 않는다. 경로 이외의 옵션은 추가 결정 후 적용 방식과 재시작 필요 여부를 정한다.

## 5. 검수

| 시나리오 | 기대 결과 |
|---|---|
| 잘못된 경로 입력·적용 | 오류 표시, 현재 정상 경로·작업 유지 |
| 폴더 선택 취소·옵션 닫기 | 입력만 한 경로 미적용 |
| 같은 경로 적용 | 불필요한 재시작 없음 |
| 정상 경로 변경 | 저장·설정 기록 후 재시작, 새 경로로 작업 복원 |
| 저장·설정 기록 실패 | 재시작 보류, 현재 작업 유지 |
| 재시작 후 실행 취소 | 이전 실행 이력 없음 |
