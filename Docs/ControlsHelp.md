# 아이콘 중심 조작 안내·도움말 기획

> 정리일: 2026-11-03
> 입력 바인딩은 기존 확정 기획을 따른다. 아이콘 중심 배치·시스템 메뉴·꾸미기 이력 범위는 최신 사용자 결정을 반영한다.
> 첫 사용 안내의 세부 노출은 권장안이며, 새 UI 구현 완료를 뜻하지 않는다.

## 1. 빠른 안내와 자세한 안내

- 현재 카메라 출력 영역의 왼쪽 아래에 빠른 조작 안내를 둔다.
- 마우스 그림의 해당 버튼 강조·드래그 화살표와 `회전`·`화면 이동`·`거리`의 짧은 글자를 사용한다. 설명 전체를 긴 문장으로 상시 노출하지 않는다.
- 좌·우 중 하나와 좌+우 동시 누름을 그림에서 구분한다. 색만으로 버튼을 구별하지 않는다.
- 안내의 정보 아이콘에서 자세한 조작 안내를 펼친다. 툴팁과 접근 이름은 `조작 안내`다.
- 자세한 안내는 비모달이다. 밖의 카메라 영역에서 연습할 수 있고, 안내 안의 클릭·휠은 카메라로 전달하지 않는다.
- 짧은 문구·마우스 그림 자체는 입력을 막지 않는다. 정보 아이콘처럼 실제 조작부만 입력을 받는다.
- 패널 여닫기·가로/세로 전환 시 카메라 영역의 왼쪽 아래로 따라간다. 패널 밑에 가리거나 화각 버튼과 겹치지 않게 한다.
- X·정보 아이콘 재선택·적절한 ESC로 자세한 안내를 접는다. 바깥 카메라 조작만으로 자동으로 닫지 않는다.

## 2. 첫 사용 안내 권장안

1. 경로 검사·복구·캐릭터 조립을 먼저 완료한다. 도움말이 필수 안내를 덮지 않게 한다.
2. 안내 미확인 첫 정상 진입에는 자세한 안내를 펼친다. 패널은 기본처럼 닫힘이다.
3. 사용자는 그대로 조작하거나 `확인했어요`로 접는다. 필수 튜토리얼 단계로 편집을 막지 않는다.
4. 명시적 확인 여부만 앱 UI 설정에 보관한다. 이후에는 짧은 안내·정보 아이콘을 보인다.
5. 아이콘으로 언제든 다시 연다. 코디 가져오기·코디 초기화는 도움말 확인 여부를 바꾸지 않는다.

## 3. 실제 안내 내용

| 조작 | 자세한 안내 문구 |
|---|---|
| 왼쪽 또는 오른쪽 버튼 드래그 | 캐릭터 주위를 돌아봅니다 |
| 왼쪽+오른쪽 버튼 동시 드래그 | 화면을 좌우·위아래로 옮깁니다 |
| 마우스 휠 | 카메라 거리를 조절합니다 |
| 0.5x·1x·3x | 광각·기본·망원 화각을 선택합니다. 휠 거리 조절과 별개입니다 |
| 눈 아이콘·F1 | 전체 UI를 숨기거나 다시 표시합니다 |
| 가장자리 탭 | 꾸미기 패널만 열거나 접습니다 |
| 최상단 되돌리기·다시 실행 아이콘 | 꾸미기 편집만 되돌립니다. Ctrl+Z·Ctrl+Y도 사용할 수 있습니다 |
| 메뉴 아이콘·ESC | 시스템 메뉴를 열거나 닫습니다 |

- 휠 위/아래 방향·감도는 최종 조정 전이므로 임의로 방향을 확정해 안내하지 않는다.
- UI 위에서 시작한 드래그·목록 위 휠은 해당 UI 조작이다. 카메라는 남은 미리보기 영역에서 조작한다.
- 꾸미기 실행 취소는 외형·의상·염색·배경과 도입 후 연출 편집값을 대상으로 한다. 카메라 회전·거리·화각은 되돌리지 않는다.
- 아이콘 버튼에는 현재 동작을 알리는 툴팁을 제공한다. 첫 사용 안내에는 툴팁을 기다리지 않아도 핵심 조작이 보인다.
- Ctrl+S·Ctrl+O·별도 카메라 초기화 같은 미정 단축키는 추가하지 않는다.

## 4. 꾸미기와 염색

- 외형·의상·배경 제목을 눌러 펼치고, 목록에서 이름이나 데이터 ID로 검색한다고 설명한다.
- 피부·헤어·눈 색은 색 시트 목록에서 고른다.
- 의상 염색은 의상 바로 아래 실제 파트 견본에서 연다. 색 선택·HEX 입력·미리보기·적용·취소를 설명한다.
- 다른 의상을 고르면 새 의상 기본색으로 시작한다고 알린다.
- 적용 불가·다른 의상에 가림의 사유는 항목 바로 아래에서 확인한다. 이 상태와 에디터 숨김을 같은 의미로 설명하지 않는다.
- 피커를 연 채 남은 카메라 영역에서 돌려볼 수 있다. 다른 편집을 시작하면 현재 미리보던 색을 적용하는 Dye.md의 구현 선택을 설명한다.
- 패널 접기·F1은 미확정 색을 적용·취소하지 않는다. 패널·UI 복귀 후 이어서 편집한다.
- 행동·카메라 쳐다보기는 지원 검증 뒤 실제 UI에 도입할 때 설명도 추가한다.

## 5. 시스템 작업 명칭

| 표시 이름 | 설명 |
|---|---|
| 자동 저장 | 마지막 작업을 다음 실행에 이어갑니다 |
| 내보내기(Export) | 현재 외형·의상·염색·배경·카메라를 JSON 파일로 보관합니다 |
| 가져오기(Import) | JSON 파일을 검사하고 작업을 교체합니다. 성공하면 꾸미기 이력이 초기화됩니다 |
| 초기화 | 현재 성별 기본 코디·기본 카메라로 돌아갑니다. 배경은 유지하며 실행 취소할 수 없습니다 |
| 옵션 | 게임 설치 경로를 바꾸고 적용 후 다시 시작합니다 |
| 종료 | 대기 중 작업을 저장한 뒤 종료합니다 |

- 수동 파일 작업의 명칭은 내보내기·가져오기로 통일한다. 자동 저장을 내보내기라고 부르지 않는다.
- 경로 변경 재시작은 작업을 복원하지만 실행 취소 이력은 비워진다고 안내한다.
- 시스템 메뉴는 종료 확인 팝업을 대체한다. 기본 ESC를 종료 요청으로 설명하지 않는다.

## 6. ESC·F1·입력 우선순위

- 현재 입력을 소유한 가장 위 UI 한 곳이 ESC를 처리한다. 부모·뒤 화면으로 같은 이벤트를 다시 넘기지 않는다.
- 파일 대화상자·옵션·초기화·오류 화면과 그 안의 목록이 있으면 먼저 처리한다.
- 활성 시스템 메뉴에서 ESC는 메뉴만 닫는다. 옵션에서 ESC는 메뉴로 돌아간다.
- 일반 편집 중에는 드롭다운 → 컬러피커 → 자세한 안내를 먼저 닫는다. 그 밖의 UI가 없으면 ESC로 시스템 메뉴를 연다.
- 패널은 탭으로 여닫는다. ESC가 패널 접기와 메뉴 열기를 함께 실행하지 않게 한다.
- UI 숨김 중 ESC는 메뉴를 임시로 열고, 메뉴 닫기 후 원래 UI 숨김으로 돌아온다.
- 모달·파일 대화상자 중 F1은 뒤 UI를 전환하지 않는다.
- 텍스트 입력 중 Ctrl+Z가 입력란과 전체 꾸미기를 동시에 되돌리지 않게 한다.
- 도움말 열림·확인·UI 숨김은 꾸미기 이력과 코디 JSON에 넣지 않는다.
