# 촬영모드 후속 검토

> 정리일: 2026-11-02
> 확정 사항·제안·미정 표기를 유지한다. 구현 완료를 의미하지 않는다.
> 화면·상태 전환은 [프로그램 플로우](ProgramFlow.md)를 참고한다.

## 후속 촬영모드

독립 촬영모드는 후속 검토다. UI 숨기기와 렌즈 화각은 별도 촬영모드 진입 없이 꾸미기 화면에 제공한다(사용자 결정 2026-11-02).

- UI 숨김은 [창·UI](WindowAndCustomizationUI.md), 0.5x·1x·3x 화각 프리셋은 [카메라](Camera.md)에 확정 사양을 기록한다.
- 카메라 쳐다보기는 구현 가능성 검증 후 도입한다. 행동도 구현 가능한 범위를 확인해 도입한다. 데이터 근거와 검증 조건은 [스튜디오 기능 검토](StudioFeatureReview.md)를 따른다.
- 배경 선택은 다른 에이전트가 구현·기획을 먼저 작성 중이다. 해당 작업이 끝난 뒤 재검토한다. 이번 검토에서 배경 사양을 확정하거나 덮어쓰지 않는다.
- 무기 표시 전용 옵션은 보류한다. 현재는 무기 미장착으로 표시하지 않을 수 있다.
- 이미지 저장용 구도·화면비·촬영 프레임은 별도 촬영 버튼을 검토할 때 다시 다룬다. 이번 꾸미기 기능에 추가하지 않는다.
- 표정·추가 조명·펫·AR·최근 사용·즐겨찾기는 이번 사용자 결정으로 새 필수 기능에 포함하지 않는다.
- 스튜디오 배경의 구현·기획 초안은 [스튜디오 배경](Background.md)에 있다(2026-11-02). 외부 검토 후 재검토한다.
- 꾸미기 카메라가 게임 촬영모드 조작을 사용한다는 것과 촬영 기능 전체를 구현한다는 것은 구분한다.
- 캡처 저장 폴더 정책은 JSON 저장 폴더와 자동으로 공유하지 않는다.
- 사진 모드와 스튜디오 모드의 구분을 그대로 제품에 적용할지는 미정이다.

## 남은 결정

- 시선 추적과 행동의 실제 지원 범위·동작 검증. 표정·추가 조명·결과 저장의 구체적 범위는 후속 검토다.
- 촬영모드의 진입·복귀 흐름은 기능 범위 결정 후 ProgramFlow.md에 추가한다.
