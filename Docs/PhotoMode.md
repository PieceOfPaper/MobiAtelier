> 정리일: 2026-11-02
> 확정 사항·제안·미정 표기를 유지한다. 구현 완료를 의미하지 않는다.
> 화면·상태 전환은 [프로그램 플로우](ProgramFlow.md)를 참고한다.

## 후속 촬영모드

촬영모드는 **검토 예정**이며 이번 기본 흐름에 포함하지 않는다.

- 캡처 저장, UI 숨김, 화면비, 포즈·표정, 배경·조명 등의 후보를 별도로 검토한다.
- 스튜디오 배경 선택은 꾸미기 장면 기능으로 먼저 다룬다([스튜디오 배경](Background.md)).
- 꾸미기 카메라가 게임 촬영모드 조작을 사용한다는 것과 촬영 기능 전체를 구현한다는 것은 구분한다.
- 캡처 저장 폴더 정책은 JSON 저장 폴더와 자동으로 공유하지 않는다.
- 사진 모드와 스튜디오 모드의 구분을 그대로 제품에 적용할지는 미정이다.

## 남은 결정

- 촬영 기능·포즈·표정·배경·조명·화면비·결과 저장의 구체적 범위.
- 촬영모드의 진입·복귀 흐름은 기능 범위 결정 후 ProgramFlow.md에 추가한다.
