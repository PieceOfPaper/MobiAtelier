# 머리카락·치마 간이 물리

> 정리일: 2026-11-20
> 구현: 2026-11-20(1차). 확정·제안·미정 표기를 유지한다.

## 1. 결정

- [확정] 게임의 천 물리(MagicaCloth 1세대)를 플러그인 없이 간이 본 물리로 재현한다. 사용자 결정(2026-11-20)이다.
- [확정] 게임 설정값은 설치 폴더 프리팹에서 직접 읽는다. 값을 앱에 옮겨 적지 않는다. 패치로 값이 바뀌면 그대로 따라간다.
- [확정] 원본 계산 코드(Burst 잡)는 옮기지 않는다. 설정값의 뜻(MagicaCloth 1세대 문서)에 맞춰 위치 기반 물리(PBD)로 새로 짠다. 게임과 흔들림이 똑같지 않다.
- [확정] 옵션에서 켜고 끈다(기본 켬, 바로 적용, 앱 설정에 기록). 사용자 결정(2026-11-20): 게임과 움직임이 아직 많이 달라 끌 수 있게 한다([Options.md](Options.md) 3-1).

## 2. 게임 데이터 [확인: 설치본]

- 게임은 MagicaCloth 1세대(네임스페이스 `MagicaCloth`, `MagicaBoneCloth`·`MagicaBoneSpring` 등)를 쓴다. 2세대(`MagicaCloth2`)는 없다.
- 플레이어 프리팹 5,706개 중 968개에 `MagicaBoneCloth` 가 있다(묶음 1,318개, 모두 알고리즘 2). 헤어·원피스 약 절반, 로브 대부분, 모자 일부. 신발에는 없다.
- 한 묶음에 있는 것:
  - 설정값 `clothParams`: 반지름·질량·중력·저항·최대 속도·회전 복원·각도 제한·뿌리 거리 제한·충돌 등. 대부분 깊이(뿌리 0 → 끝 1)에 따라 변하는 값이다.
  - 미리 계산한 데이터 `clothData`: 입자 목록(`useVertexList` → `useTransformList` 의 본), 고정·이동(`selectionData`, 2 = 고정·1 = 이동), 깊이(`vertexDepthList`), 부모(`parentList`).
  - 충돌체 목록 `teamData.colliderList`: 같은 프리팹 안의 `MagicaCapsuleCollider`(중심·축·길이·양 끝 반지름)·`MagicaSphereCollider`(중심·반지름). 몸 본(`_Spine1`·`_L UpperArm` 등) 아래 오브젝트에 붙어 있다.
  - 게임이 덧붙인 키 단계별 충돌체·본 위치 프리셋(`medium/tallHeightMorphPresetDatas` 등).
- 한 번들에 다른 프리팹(타이틀 화면 캐릭터 등)이 같이 들어 있을 수 있다. 프리팹 루트 이름이 같은 것만 쓴다.
- 깊이별 값(BezierParam.Evaluate) [확인: 게임 코드]: 끝값을 쓰지 않으면 시작값 하나. 곡선을 쓰지 않으면 선형. 곡선을 쓰면 제어점 = 끝값 + (시작값 − 끝값) × (0.5 + 0.5 × 곡선값)인 2차 베지어.
- 알고리즘 2 이면 회전 복원·각도 제한에 `restoreRotation2`·`clampRotationAngle2`·`restoreRotationVelocityInfluence2` 를 쓴다 [확인: 게임 코드].

## 3. 앱의 계산

- 조립: 보이는 헤어·의상 파츠의 프리팹에서 묶음을 읽는다. 입자 본은 파츠 전용 본 → 캐릭터 본 순으로 이름으로 찾는다. 충돌체는 부모 본 + 프리팹의 국소 위치다. 본을 못 찾은 묶음은 뺀다.
- 재생: 모든 본 보정(시선·손 IK·파츠 본 동기화) 뒤에 계산한다. 프레임마다 한 단계 이상, 단계 길이는 1/90초 이하로 프레임 시간을 나눈다(최대 4단계). 단계마다 애니메이션 자세를 지난 프레임과 이번 프레임 사이로 보간한다.
  - 저항·회전 복원 값은 1/90초 한 단계당 비율로 보고, 단계 길이에 맞춰 거듭제곱으로 바꾼다.
  - 처음에는 1/90초 고정 간격으로 돌렸다. 화면 갱신이 더 빠르면 계산 없는 프레임에 본이 지난 물리 위치로 되돌아가 떨렸다(2026-11-20 사용자 제보 "펄럭임").
  1. 속도 적분: 저항(단계마다 × (1 − 저항)), 중력(방향 × 값), 최대 속도. 고정 입자는 애니메이션 위치로 옮긴다.
  2. 거리 연결(`structDistanceDataList`): 사슬 위아래와, 연결 방식이 메시인 묶음의 가로·대각선 연결. 애니메이션 자세의 거리로 강도(`structDistanceStiffness`)만큼, 질량 역수로 나눠 되돌린다.
  3. 회전 제한·복원: 게임 `CompositeRotationConstraint.RotationRootLineJob` 을 옮겼다 [확인: 게임 코드]. 사슬 순서로 2회 반복한다.
     - 각도 제한: 길이는 잡 시작 길이와 현재 길이의 평균. 부모의 시뮬레이션 회전 변화를 곱한 애니메이션 방향에서 최대각을 넘으면 자른다. 선분 중점 기준으로 부모·자식을 반씩 옮긴다. 속도에는 √(saturate(최대각/90)) × (−0.3) + 0.5 만 남긴다.
     - 회전 복원: 부모의 애니메이션 방향으로 1 − (1 − 세기)^(단계 길이 × 90) 만큼 돌린다. 회전 중심은 선분 위 r 지점이고 부모·자식이 함께 움직인다. r = (방향·중력 방향 × 0.5 + 0.5)^(4 − 3·clamp01(|중력|/9.8)) × 0.2 + 0.25(아래를 향하면 0.25, 위를 향하면 0.45). 속도에는 복원 속도 영향만 남긴다.
  4. 삼각형 굽힘(`triangleBendDataList`): 공유 모서리 맞은편 두 입자의 거리 유지로 근사한다. 강도는 알고리즘 2 의 `triangleBend2`.
  5. 뿌리 거리 제한: 애니메이션 자세의 뿌리까지 거리 × 최소~최대 비율.
  6. 충돌: 구·캡슐 밖으로 입자 반지름만큼 민다.
  7. 콜라이더 관통 방지(모드 1, `penetrationDataList`): 입자를 묶인 충돌체 뒤로 넘어가지 못하게 한다. 한계점 = 기준점 + 방향 × (충돌체 반지름 − 허용 깊이), 입자는 한계점에 닿는 반지름 `penetrationRadius` 의 구 안에 둔다 [추정: 문서 "Moving Radius" 기하].
  - 처음(1차)에는 회전 제한·복원이 자식만 옮기고 메시 연결·굽힘·관통 방지가 없었다. 띠 여러 개를 메시로 묶는 의상(로스트 문스케이프 예복 앞자락 등)이 체조 모션에서 크게 일그러졌다(2026-11-20 사용자 제보).
- 결과: 본 회전만 바꾼다. 각 본이 시뮬레이션한 자식 위치를 향하게 돌린다(자식이 여럿이면 평균 방향, 회전선 평균). 고정 입자도 돈다(설치본 `useFixedNonRotation` 은 끔).
- 시간 건너뜀(시험 촬영의 시점 지정·처음 조립)에는 애니메이션 자세에서 0.6초 정착시킨 뒤 쓴다.

## 4. 옮기지 않은 것

| 항목 | 이유 |
|---|---|
| 표면 관통 방지(모드 0) | 콜라이더 모드만 옮겼다 |
| 마디 굽힘(bend)·근처 거리(near)·부피·비틀림 | 확인한 묶음은 끔. 켜진 묶음이 있는지 세지 않았다 |
| 삼각형 굽힘의 정확한 식 | 원본은 이면각을 유지한다(`restAngle`). 앱은 거리 유지로 근사한다 |
| 계산 순서·반복 횟수 | 회전 잡 안의 2회 반복만 확인했다. 잡 사이 순서·전체 반복 횟수는 읽지 않았다 |
| 캐릭터 이동·회전 관성(world influence)·순간 이동 판정 | 앱 캐릭터 루트는 움직이지 않는다 |
| 키 단계별 충돌체·본 프리셋 | 충돌체 크기는 본 크기(나이·키 보정)만 따른다 |
| 바람·거리 끄기·`MagicaBoneSpring`·`MagicaMeshCloth` | 앱에 필요한 범위 밖이다 |
| 깊이 영향(`depthInfluence`)·질량 영향 | 바람 등 외부 힘을 깊이별로 받는 비율이다(MagicaCloth 문서 "External Force"). 바람이 없어 쓰지 않는다 |
| 마찰 | 충돌 시 마찰을 계산하지 않는다(회전 잡의 마찰 비율은 1) |

- [추정] 캡슐 `length` 는 전체 길이(중심 ± 길이/2)로 본다. 저항은 1/90초 단계마다 곱한다. 원본 갱신 빈도는 90으로 둔다.

## 5. 검증

- [확인] 설치본 플레이어 프리팹 5,706개를 오류 없이 읽었다(.NET 콘솔).
- [확인] 배치 촬영(60fps, 3초, 이동 입자의 이동 거리 합 물리 ÷ 애니메이션 자세, 애니메이션에서 벗어난 최대 거리):
  - 녹스 미스티카 드레스 + 러블리 하프업 롱 헤어: 아이들 0.37 ÷ 0.41m·4cm, 전통댄스 22.2 ÷ 22.2m·19cm.
  - 로스트 문스케이프 예복 + 체조(PT): 83.7 ÷ 81.4m·42cm. 회전 잡을 옮기기 전에는 279 ÷ 81m·1.37m로 앞자락이 다리 옆으로 넘어가 일그러졌다. 정지 자세에서 앞자락이 늘어진 모양을 유지한다.
- [미확인] 앱에서 실제 움직임, 게임 화면과의 비교(흔들림 크기·처짐).
- 시험: `InstallSmokeTest -maOutfit "이름:Top=…,hair=…,cloth=swing"`(30fps 로 3초 진행, `fps=144` 로 바꿈, 로그에 최대 벗어남·이동 거리 합), `cloth=0`(끄기), `clothOff=비트`(단계 끄기: 1 충돌, 2 복원, 4 각도 제한, 8 연결·굽힘, 16 중력, 32 뿌리 거리, 64 관통 방지). 로그 "천 물리 충돌체" 줄에 충돌체 위치와 애니메이션 자세의 파고듦이 나온다.
