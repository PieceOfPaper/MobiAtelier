# 무기 자세

> 정리일: 2026-11-03
> 무기의 장착 위치(넣음·꺼냄)와 직업별 서 있기 자세. 무기 외형 선택 자체는 [의상·리소스 선택](Equipment.md)을 따른다.

## 1. 결정과 범위

| 항목 | 상태 | 내용 |
|---|---|---|
| 무기 장착점 | 확정(구현) | 무기 모델 정의의 상태별 장착점에 붙인다. 바닥에 놓이던 문제를 고친다 |
| 넣음/꺼냄 선택 | 확정(구현, 2026-11-03 사용자 요청) | 의상 › 무기 아래 "무기 자세": 넣음(기본)·꺼냄(경계)·꺼냄(전투)·꾸미기 포즈 1~3 |
| 자세 직업 | 확정(구현) | 기본은 무기 외형의 원래 직업(자동). "자세 직업"에서 바꿀 수 있다 |
| 무기 선택 제한 | 변경 없음 | 직업은 자세만 고른다. 무기 목록을 거르거나 잠그지 않는다(Equipment.md 확정 유지) |
| 꺼내기·넣기 전환 | 확정(구현, 2026-11-03 사용자 요청) | 같은 무기에서 넣음↔꺼냄을 바꾸면(편집·실행 취소·다시 실행) `ToolDraw`/`ToolUndraw` 클립을 한 번 재생한 뒤 새 자세로 넘어간다. 시작 복원·가져오기에서는 재생하지 않는다 |
| 무기 자체 애니메이션 | 확정(구현) | 활시위·오브·부채 등 무기 클립(`ModelPartAnimation`)을 몸과 같은 시간으로 재생한다 |
| 꾸미기 포즈 | 확정(구현) | 게임 꾸미기 화면의 무기 포즈(`Action` 시트 `Customize_Costume_04~06`, 직업 계열별 3종). 시작 클립 → 반복 클립, 무기는 꺼낸 상태 |

## 2. 데이터

### 장착점 (무기 모델 정의)

- `StageObjectModel.ModelPartInfo.AttachPointInfo[]`: 상태(`Undrawn`/`Drawn`)마다 붙일 본(`AttachTo`), 보임 여부(`ModelPartVisibleState`), 성별·어린 외형별 `Position`·`Rotation`(오일러 각, 도)·`LocalScale`.
- 몸 본에 `_HandtoolR/L`, `_BodytoolL/R`, `_Backtool`, `_Arm2toolL` 이 있다. `#MODEL_ROOT` 는 캐릭터 루트다.
- 무기에는 BoneTemplate 이 없다. 메시 본(`_Sword_Root` 등)은 프리팹 안에만 있으므로 프리팹 본 계층을 복제해 쓴다.
- `AlwaysInvisible` 이면 그 상태에서 숨긴다. 예: 오브·코일·너클·부채·석궁·마도서는 넣으면 사라진다.
- 한 무기 외형의 모델 배열(검+방패, 칼+칼집 등)은 모델마다 자기 장착점을 쓴다. 칼집은 꺼내도 허리에 남는다.

### 자세 클립 (`AnimationStateSet` 시트)

- 키: `AnimationGroup`(`PlayerFemale`·`PlayerMale`·`PlayerInfant`) + `Condition` + `Symbol`. 값: 클립 경로 배열.
- 꺼냄(경계) = `AlertStand`, 꺼냄(전투) = `CombatStand`. 넣음은 기존 꾸미기 아이들(`Customize_Stand`)을 그대로 쓴다. 게임도 평상시 서 있기(`PeaceStand`)에는 직업 전용 행이 없다 [확인].
- 조건 예: `Any`, `CombatJob:SwordMaster`, `CombatJob:Bard, BodyType:Fat`. 성별·체형·직업·직업 계열 사실이 모두 맞는 행 중 항목이 가장 많은 행을 고른다. 게임의 조건 결정 트리를 근사한 것이다 [추정].
- 직업이 없으면 `Any` 행(공통 `PlayerCommon_Stand_Offensive`)을 쓴다.
- 직업 클립에는 얼굴 클립이 없다. 얼굴(깜빡임·표정)은 꾸미기 아이들의 얼굴 클립을 자기 길이로 따로 반복한다.

### 꺼내기·넣기 (전환)

- 클립: `AnimationStateSet` 의 `ToolDraw`·`ToolUndraw`(직업별). 넣기는 직전(꺼낸) 자세의 직업 클립을 쓴다.
- 클립에 애니메이션 이벤트가 없다 [확인]. 무기 상태 전환 시점은 `StageTimeline` 시트(클립 이름 → 타임라인 이름) → `StageTimelines/<이름>.StageTimeline` 의 `ToolState` 트랙(파츠 종류 MainTool/SubTool/SubSubTool, 상태, 시작·끝 초)에 있다.
- 규칙: 트랙 구간 안에서는 그 상태, 밖에서는 목표 상태(꺼내기 = 꺼냄, 넣기 = 넣음). 예: 음유시인 넣기는 0~0.83초 꺼냄 → 이후 등. 트랙이 없는 클립(검술사 등)은 처음부터 목표 상태다 [추정: 트랙이 지연 구간만 기록한다고 해석].
- 파츠 종류는 모델 정의 `ModelPartInfo.AppearanceSlot` 이다.

### 꾸미기 포즈

- `Action` 시트의 `Player<Female|Male|Infant>_Customize` 그룹, `Customize_Costume_04`·`05`·`06` = 꾸미기 포즈 1·2·3. 조건은 `CombatJob:<계열 기본 직업>`(Warrior·Archer·Mage·Healer·Thief·Bard)과 체형이다. 자세 직업의 계열로 고른다 [추정].
  - 예: 전사 계열 = 견습 전사·ExpertWarrior·대검, 마법사 계열 = 견습 마법사·빙결술사·화염술사.
- 직업이 없으면 `Any` 행(기본 서 있기)을 쓴다.
- 무기 상태는 꺼냄이다. 게임도 꾸미기 포즈에 무기 꺼냄 타임라인(`Customize_ToolStateTrack`)을 쓴다.
- 포즈 클립은 얼굴 클립(`_Facial.fbx`·`.xaf`)이 있어 같은 시간으로 재생한다.

### 무기 자체 클립

- `ModelPartAnimation` 시트: (모델 정의 `ModelPartAnimationGroupName`, 몸 클립 경로) → 무기 클립. 몸 클립 전용 행이 없으면 그룹의 `Default` 행.
- 무기 프리팹 루트(복제 본의 루트)에 Animator 를 두고 같은 그래프로 평가한다. 반복 클립은 자기 길이로 반복한다.

### 자세 직업

- `Costume.EquippableCombatJobs`: 무기 외형 181개 중 162개가 직업 1개, 19개(`CustomizePreview_*`)는 비어 있다 [확인]. 여러 직업이 붙은 무기는 없다.
- `CombatJob` 시트: 이름(`DisplayName`)·계열(`CombatJobLineType`)·공개(`ShowClass`). 공개 직업 28개만 목록에 보인다. 숨김 직업은 자세 클립이 없다.

## 3. 저장

- 장면 상태 `weaponPose { stance, job }`. 선택 필드이며 없는 이전 파일은 넣음·자동으로 읽는다. 직업은 필수값이 아니다(Equipment.md).
- `stance`: `Undrawn`(빈 값 포함)·`Alert`·`Combat`·`Pose1`~`Pose3`. `job`: 비면 자동.
- 꾸미기 이력·자동 저장·내보내기에 포함된다. 초기화하면 넣음·자동으로 돌아간다.
- 무기가 표시되지 않으면(미착용·미적용·가림) 꺼냄을 골라도 넣은 자세로 표시하고 패널에 안내한다. 선택은 유지한다.

## 4. 확인 결과와 남은 확인

- [확인] 배치 조립 촬영: 여성 검술사(넣음·경계·전투), 전사 검+방패, 빙결술사 오브(넣으면 숨김), 궁수, 기사(넣으면 등), 직업 없는 무기(공통 자세), 음유시인 Fat 전용 클립, 12세 검술사, 직업 변경(검+방패 + 댄서 자세), 남성 검술사·대검·듀얼블레이드.
- [확인] 빌드 실행: 패널의 "무기 자세"·"자세 직업" 표시, 자세 적용, `autosave.json` 의 `weaponPose` 저장.
- [확인] 배치 조립 시점 촬영(2026-11-03): 검술사 꺼내기(0초 허리에서 쥠 → 0.3초 들어 올림), 검술사 넣기(손 → 0.8초 허리), 음유시인 넣기(0.3초 손 → 1.3초 등), 빙결술사 포즈 2(오브 클립 2개), 전사 포즈 1(시작 1.20초 → 반복 2.67초), 궁수 꺼냄(활 클립).
- [확인] 빌드 실행: 패널에서 넣음 → 꺼냄 편집, 재실행 시 꺼냄 복원(도입 없음).
- [미확인] 실시간 앱에서 전환 클립이 보이는지(촬영 시점이 0.25초라 판별 못 함), 드롭다운 마우스 조작, 손·무기 위치가 모든 무기에서 맞는지. 모델 정의 `MeshVisibleStateOverrides`(22개)·`TransformOverrides`(1개)는 적용하지 않았다.
- 부분 복원: 없는 자세 직업 ID·모르는 자세 값은 시작 복원·가져오기 안내에 표시하고 공통 자세·넣은 자세로 대신 표시한다. 값은 지우지 않는다.
- 남성 듀얼블레이드처럼 시트가 다른 성별 클립을 가리키는 행도 있다. 시트 값을 그대로 따른다.
