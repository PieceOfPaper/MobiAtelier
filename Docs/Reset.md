# 초기화 기획

> 정리일: 2026-11-03
> 버튼 제공과 이력 처리의 확정 사항을 기록한다. 구현 완료를 의미하지 않는다.

## 확정 사항

- 시스템 메뉴의 초기화 항목에서 진입한다. 2026-11-03 사용자 결정으로 이전 꾸미기 창 공통 작업 영역 배치를 대체한다.
- 초기화가 성공하면 실행 취소·다시 실행 이력을 모두 비운다. 초기화 자체를 실행 취소할 수 있는 작업으로 기록하지 않는다.
- 초기화된 장면을 새 편집 기준으로 삼고, 이후 변경부터 이력을 쌓는다.
- 초기화 준비가 실패하면 기존 장면과 이력을 유지한다.
- 현재 작업을 초기화하는 동작이며 사용자가 별도로 저장한 JSON 파일을 삭제하거나 덮어쓰지 않는다.

## 초기화 기준과 확인

**확정 (2026-11-02)**
- 현재 성별을 유지하고 해당 성별의 `MaleAppearance_Default_01` 또는 `FemaleAppearance_Default_01` 기본 외형을 적용한다. 나이·체형·키·얼굴·헤어·색상도 프리셋 기준으로 돌린다. 성별을 다시 추첨하지 않는다.
- 의상은 Startup.md의 초보자 기본 상의·하의·신발로 돌리고, 나머지 액세서리·무기·꾸밈·직접 리소스 선택은 해제한다. 사용자 염색은 제거하고 원본 기본색을 적용한다.
- 호환성 때문에 따로 보관한 이전 외형 선택도 지운다. 카메라는 현재 화면비에 맞는 기본 구도로 돌린다.
- 배경은 유지한다(2026-11-03 추천안 채택). 패널 열림·크기·펼침 상태, 앱 창 배치, 설치 경로·최근 내보내기 폴더 등 환경 설정도 유지한다.
- 확인 팝업 문구: **현재 코디를 초기화하시겠습니까? 외형·의상·염색·카메라가 기본 상태로 돌아가며 실행 취소할 수 없습니다.**
- 초기화 버튼으로 확정한다. 취소·X·바깥 클릭·ESC는 취소하며 기존 작업과 이력을 유지한다. 뒤 UI·카메라로 클릭을 전달하지 않는다.

## 적용 순서

- 새 상태와 모델을 준비한 뒤 정상 적용과 이력 삭제를 함께 확정한다.
- 준비 실패 시 기존 장면·선택·이력을 유지하고 이유를 표시한다.
- 초기화된 상태도 마지막 작업 자동 저장 대상으로 삼는다. 자동 저장 실패 안내는 저장 기획을 따른다.
