# 초기화 기획

> 정리일: 2026-11-01
> 버튼 제공과 이력 처리의 확정 사항을 기록한다. 구현 완료를 의미하지 않는다.

## 확정 사항

- 꾸미기 창의 공통 작업 영역에 초기화 버튼을 제공한다.
- 초기화가 성공하면 실행 취소·다시 실행 이력을 모두 비운다. 초기화 자체를 실행 취소할 수 있는 작업으로 기록하지 않는다.
- 초기화된 장면을 새 편집 기준으로 삼고, 이후 변경부터 이력을 쌓는다.
- 초기화 준비가 실패하면 기존 장면과 이력을 유지한다.
- 현재 작업을 초기화하는 동작이며 사용자가 별도로 저장한 JSON 파일을 삭제하거나 덮어쓰지 않는다.

## 후속 결정

- 초기화의 기준 상태와 범위: 최초 기본 외형으로 돌릴지, 현재 성별·외형 일부를 유지할지, 의상·염색·카메라를 어디까지 초기화할지.
- 초기 착용 의상은 Startup.md에서도 미정이다. 초기화 버튼 추가만으로 해당 의상을 임의 채택하지 않는다.
- 초기화 전 확인 팝업 제공 여부와 문구. 기존 종료 팝업의 동작을 초기화에 자동 적용하지 않는다.

## 구현 제안

- 새 상태와 모델을 준비한 뒤 정상 적용과 이력 삭제를 함께 확정한다.
- 초기화된 상태도 마지막 작업 자동 저장 대상으로 삼는다. 자동 저장 실패 안내는 저장 기획을 따른다.
- UI 패널 배치·게임 설치 경로 등 환경 설정은 코디 초기화와 분리하는 것을 제안한다.
