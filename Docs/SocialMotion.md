# 소셜 모션 미리보기

> 정리일: 2026-11-03

게임 "모션" 메뉴의 행동(화남, 춤 등)을 캐릭터에 재생해 보는 보기 도구다. 꾸미기 값이 아니며 저장하지 않는다.
데이터 근거와 첫 재생 시험은 [스튜디오 기능 검토](StudioFeatureReview.md) 3장에 있다.

## 1. 성격 (확정, 2026-11-03)

| 항목 | 내용 |
|---|---|
| 분류 | 카메라·화각과 같은 보기 도구. 꾸미기(외형·의상·염색·배경)에 넣지 않는다 |
| 저장 | 자동 저장·내보내기(Export) JSON·시작 복원에 넣지 않는다. 앱을 켜면 항상 기본 동작으로 시작한다 |
| 이력 | 실행 취소·다시 실행 이력에 넣지 않는다 |
| 초기화 | 꾸미기 초기화와 관계없다. 초기화로 다시 조립되면 3장의 조립 규칙을 따른다 |

## 2. 위치와 UI (확정, 2026-11-03)

- 카메라 출력 영역 오른쪽 아래에 `모션` 버튼을 둔다. 하단 중앙의 화각, 왼쪽 아래의 조작 안내와 같은 줄이다([화면 배치](WindowAndCustomizationUI.md) 항목 T).
  - 좁아서 화각과 겹치면 화각 위 줄로 올린다.
- 패널을 여닫으면 카메라 출력 영역을 따라 움직인다. 패널이 닫혀 있어도 쓸 수 있다.
- 버튼을 누르면 검색 목록이 열린다(아래 공간이 모자라면 위로 연다).
  - 묶음 없이 한 목록이다. 시트 순서대로 둔다.
  - 표기는 `ID - 이름`(예: `Angry - 화남1`)이다. ID와 이름 모두 검색한다.
  - 아이콘은 쓰지 않는다.
- 항목을 고르면 바로 재생하고 목록을 닫는다. 같은 항목을 다시 고르면 처음부터 재생한다.
- 재생 중에는 버튼이 `▶ ID - 이름` 과 ■로 바뀐다. ■는 멈추고 기본 동작으로 돌아간다. 한 번 재생형이 끝나면 버튼이 `모션`으로 돌아온다.
- ESC는 열린 목록을 먼저 닫는다. 그다음 ESC가 시스템 메뉴를 연다([ESC 입력 소유권](SystemMenu.md)).
- F1·눈 버튼으로 UI를 숨겨도 재생은 계속한다.

## 3. 재생 규칙 (확정, 2026-11-03)

| 항목 | 내용 |
|---|---|
| 목록 범위 | 2인 모션(`Logic`, 커플댄스 등 5개)만 뺀다. 무작위 모션(`Random`)은 넣는다 |
| 잠금 모션 | 게임에서 아이템으로 해금하는 모션도 모두 보인다. 해금 조건은 숨김 데이터 판정이 아니다 |
| 데이터 연결 | `SocialAction.Actions[].Name` → `Action`(그룹 `PlayerFemale`·`PlayerMale`·`PlayerInfant`, 조건 `BodyType`·`Clothing`) → `StartClipPath`·`LoopClipPath`. 얼굴은 클립 이름 + `_Facial`(fbx·xaf) |
| 성별·나이별 클립 | 시트 경로를 그대로 쓴다. 전통댄스는 남성·어린 외형도 여성 클립을 쓴다 |
| 옷 조건 | 입은 의상 모델의 `ClothingCondition`(ShortSkirt·LongSkirt)으로 앉기 등의 클립을 고른다 |
| 무작위 모션 | 고를 때마다 `Actions` 중 하나를 고른다(가중치가 모두 같다). 다시 조립해 이어 재생할 때는 고른 것을 유지한다 |
| 시작 클립만 있음 | 한 번 재생한 뒤 현재 무기 자세의 기본 동작으로 돌아간다 |
| 반복 클립만 있음 | ■를 누를 때까지 반복한다 |
| 시작 + 반복 | 시작 클립 뒤 반복 클립을 ■까지 반복한다 |
| 전환 | 시트의 `FadeInTime`·`FadeOutTime`으로 기본 동작과 섞는다. 기본 동작은 아래에서 계속 흐른다 |
| 무기 | 재생 중에는 넣은 위치로 옮긴다. `HideWeapon` 행동은 숨긴다. 끝나면 원래 무기 자세로 돌아간다 |
| 재생 중 꾸미기 편집 | 다시 조립한 캐릭터에서 같은 시점부터 이어서 재생한다 |
| 성별·나이 변경 | 새 외형의 클립으로 이어서 재생한다. 맞는 클립이 없으면 멈추고 알린다 |
| 몸이 돌거나 움직이는 동작 | 원본 그대로 둔다. 화남은 돌아섰다가 정면으로 돌아온다(촬영 확인) |
| 얼굴 클립 없음 | 기본 동작의 얼굴을 그대로 쓴다 |
| 실패 | 클립을 읽지 못하면 알리고 기본 동작으로 둔다. 장면·저장은 바뀌지 않는다 |

## 4. 소품·이펙트·연출 트랙 (확정, 2026-11-03)

- 클립 이름의 `StageTimeline`과 행동별 `ActionStageTimeline`(시작·반복 클립 각각)을 함께 읽는다.
  - 쓰다듬기는 고양이 소품이 클립 쪽, 이펙트가 행동 쪽에 있다. 모자마술 햄스터·부엉이·토끼는 행동 쪽 타임라인으로 다른 소품을 쓴다.
  - 두 쪽에 같은 프리팹·재질이 같은 구간·같은 시각으로 있으면 하나만 쓴다(수박먹기) [추정: 게임의 합치는 규칙은 확인하지 못했다].
- 조사 범위: 2인 모션을 뺀 목록의 타임라인. 카메라·진동 트랙은 소셜 모션에 없다. 모션 클립에는 애니메이션 이벤트가 없다(6개 확인).
- 쓰는 트랙:

| 트랙 | 구간·모션 수 | 처리 |
|---|---|---|
| Prop | 262구간, 42개 | 소품 프리팹을 `AttachBoneName`(손 `_HandtoolR`·`_HandtoolL`, `#MODEL_ROOT`) 본에 붙이고 구간 동안만 보인다. 캐릭터 셰이더(MMN/CH) 재질은 앱 캐릭터 셰이더로 바꾼다. 배경 셰이더(MMN/BG) 소품은 배경 패스로 그려진다 |
| PropAnimation | 219구간, 36개 | 같은 키의 소품에 소품 자체 클립을 구간 시작 기준 시간으로 재생한다 |
| Effect | 657구간, 66개 | 프리팹(파티클·메시)을 기준(캐릭터 본 또는 소품 본)에 놓고 구간 동안 재생한다. `Attached`는 따라 움직이고 아니면 켜진 위치에 남는다. 반복 구간이 처음으로 돌아가면 다시 재생한다 |
| IKControl | 107구간, 16개 | 손바닥(`_L Palm`·`_R Palm`)을 목표로 옮기는 2본 IK(위팔·아래팔). 손 방향은 클립 값을 유지한다. 목표: `IKReferenceableEffectBone`·`TargetBone`은 그 본 위치, `DisplacementPosition`은 Target 본이 Displacement 본에 닿게 같은 만큼 옮긴다. 구간 페이드 곡선을 쓴다. 캐릭터에 없는 `_Lip_Effect`는 `_Lip_Center`로 대신한다 [추정] |
| AdditiveRenderer | 12구간, 3개 | 같은 메시·본을 쓰는 렌더러를 하나 더 만들어 덧그림 재질을 모든 서브메시에 그린다(볼 붉어짐·땀방울). 재질 값 곡선을 구간 진행도로 적용한다. 표정 블렌드셰이프를 따라간다 |
| ObjectVisibility | 12구간, 3개 | 대상 렌더러를 구간 동안 그리지 않는다(`forceRenderingOff`). 슬롯: ActorModel(무기 뺀 캐릭터), MainTool·SubTool·SubSubTool(무기), Accessory0~2(귀·눈·얼굴 장식 [추정]), Custom(렌더러 이름, 캐릭터·소품) |
| ShaderProperty | 6구간, 2개 | 대상 렌더러에 MaterialPropertyBlock 으로 값을 덮고 구간이 끝나면 지운다. 앱 캐릭터 셰이더에 없는 속성(_OverrideColor·_HalftoneClip)은 보이는 변화가 없다 |

- 쓰지 않는 트랙: 소리(6장), 무기 넣음 ToolState(18구간, 앉기. 소셜 모션은 이미 모든 행동에서 무기를 넣는다). 행동을 읽을 때 안 쓴 트랙 수를 로그에 남긴다.
- 소품 크기 보정(`DefaultScaleSensitivity`)과 소품 위치 표(`PropTransformDataArr`)는 아직 쓰지 않는다. 어린 외형에서 소품 크기가 게임과 다를 수 있다.

## 6. 소리 (보류, 2026-11-03)

사용자 결정으로 소리는 보류한다. 앱에 소리 재생 기능이 없다. 도입할 때 아래를 넣는다.

| 모션 | 트랙 | 내용 | 그룹 |
|---|---|---|---|
| `Dance - 전통댄스` | Footstep | 발자국 소리 `Sound_FootStep_Human_Left`·`Right` | 여·남·어린 |
| `Bye - 손인사1` | Footstep | 발자국 소리 `Sound_FootStep_Human_Left`·`Right` | 여 |
| `Heart - 하트` | Footstep | 발자국 소리 `Sound_FootStep_Human_Left`·`Right` | 여·남·어린 |
| `Rest - 앉기` | Footstep | 발자국 소리 `Sound_FootStep_Human_Left`·`Right` | 여·남·어린 |
| `Rest - 앉기` | Sound | 효과음 `SoundGroup_Emotion` 의 `SFX_Sit_Ground`(바닥에 앉는 소리) | 여·남·어린 |
| `ItsYou - 바로너!` | Footstep | 소리가 아니라 발자국 이펙트 `FX_FootStep_Human_Right` 다. Footstep 트랙과 함께 보류한다 | 여·남·어린 |

- 발자국 소리·이펙트 이름은 리소스 `FootstepPresentation/<이름>.sjon` 에 정의가 있다. 실제 소리 파일 연결은 그 데이터와 `Sound/SoundGroup_*.prefab` 에서 확인해야 한다.
- 소리 파일은 설치 폴더 번들에 Unity AudioClip(.wav)으로 있다(`Sound/AudioClips/...`).
- 도입 때 필요한 것: 소리 재생 기능, 음량·끄기 옵션([옵션](Options.md)의 후보로 사용자와 정한다), UI 숨김·창 비활성 중 처리.
