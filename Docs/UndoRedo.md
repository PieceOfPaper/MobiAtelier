# 꾸미기 실행 취소·다시 실행 기획

> 정리일: 2026-11-03
> 2026-11-03 사용자 결정이 이전의 카메라 포함 장면 이력 정책을 대체한다. 기획 확정과 구현 완료를 구분한다.
> 상태 전환은 [프로그램 플로우](ProgramFlow.md)를 따른다.

## 1. 위치와 입력

**확정**
- 꾸미기 창 최상단의 제목·탭 영역에 실행 취소·다시 실행 아이콘을 나란히 둔다. 별도 페이지 전환 탭을 추가한다는 뜻은 아니다.
- 아이콘은 되돌리기·다시 실행 방향을 구분한다. 툴팁은 `꾸미기 실행 취소 (Ctrl+Z)`·`꾸미기 다시 실행 (Ctrl+Y)`다.
- 해당 이력이 없으면 비활성 표시한다. 시스템 메뉴의 파일 작업과 분리한다.
- Ctrl+Z·Ctrl+Y는 같은 명령을 실행한다. 꾸미기 창을 접거나 UI를 숨겨도 단축키는 사용할 수 있다. 모달·파일 대화상자·텍스트 입력의 입력 소유권은 우선한다.

## 2. 이력 범위

**확정: 꾸미기 창에서 바꾸는 편집값을 대상으로 한다.**

| 구분 | 이력 | 예 |
|---|---|---|
| 캐릭터 외형 | 포함 | 성별·체형·키·나이·얼굴·헤어·눈·입·꾸밈·외형 색 선택 |
| 의상·액세서리·무기 | 포함 | 부위별 선택·착용 해제·호환 상태에 따라 보관되는 선택 |
| 의상 염색 | 포함 | 파트별 사용자 색·기본색 복원 |
| 배경 | 포함 | 꾸미기 창의 배경 선택. 2026-11-02의 이력 포함 제안을 채택한다 |
| 소셜 모션 | 제외(2026-11-03) | 저장하지 않는 보기 도구다([소셜 모션](SocialMotion.md)) |
| 향후 연출 | 지원 검증·도입 후 정함 | 시선 토글 등. 매 프레임 재생 시간은 제외 |
| 카메라 | 제외 | 회전·팬·거리·0.5x/1x/3x 화각 |
| UI·환경 설정 | 제외 | 패널 여닫기·펼침, UI 숨김, 도움말, 시스템 메뉴·옵션 |

카메라·배경 등 장면 값의 JSON 내보내기 범위와 실행 취소 범위는 다르다. 카메라를 이력에서 제외해도 자동 저장·JSON 복원은 유지한다.

## 3. 이력의 시작과 초기화

- 현재 실행에서 정상 복원·최초 조립한 꾸미기 값을 시작 기준으로 삼는다.
- JSON 가져오기 또는 코디 초기화가 성공하면 두 이력을 비우고 새 기준에서 시작한다. 해당 동작 자체는 실행 취소하지 않는다.
- 가져오기·초기화가 취소·실패하면 기존 작업과 이력을 유지한다.
- 앱 재시작과 경로 변경에 따른 재시작도 이전 실행의 이력을 복원하지 않는다. 마지막 작업 값만 복원한다.
- 자동 저장·일반 JSON 내보내기는 이력을 지우지 않는다. 이력은 JSON·자동 복원 파일에 저장하지 않는다.

## 4. 복원 단위와 구현 주의

- 옷 선택과 그에 따른 기본 염색·다른 부위 가림 재평가는 한 작업이다. 실행 취소 시 이전 옷과 그 사용자 염색을 함께 복원한다.
- 외형 변경에 따른 호환 불가·필수 외형 대체도 같은 작업으로 복원한다.
- 컬러피커 연속 미리보기는 매 프레임 기록하지 않는다. 적용된 색 변경을 한 작업으로 기록한다. 취소·실패는 기록하지 않는다.
- 정상 배경 선택 한 번은 한 작업이다. 실패해 이전 배경을 유지한 요청은 기록하지 않는다.
- 실행 취소 뒤 새 꾸미기 편집이 확정되면 다시 실행 분기를 비운다. 카메라·UI 조작만으로 다시 실행 분기를 비우지 않는다.
- **EditState 전체를 과거 값으로 교체하면 안 된다.** 꾸미기 필드만 복원하거나 현재 카메라·환경 상태를 유지하며 복원한다.
- 복원 후 호환·공개 제한·리소스 상태를 재평가하고, 성공한 결과를 장면·UI·자동 저장에 함께 반영한다.
- 텍스트 입력란의 Ctrl+Z와 전역 꾸미기 취소가 동시에 실행되지 않게 한다.
- 연속 편집 묶음·이력 메모리 관리의 세부는 구현 중 조정한다. 임의 개수 제한으로 이번 실행의 편집을 잘라내는 정책은 확정하지 않았다.

## 5. 검수

- 2026-11-03 구현 보완: 이력 복원도 현재 공개 범위와 실제 조립 결과를 다시 검사한다. 캐릭터·배경을 모두 준비한 뒤 성공할 때만 장면과 이력 분기를 함께 바꾼다. 실패 시 현재 배경을 되돌려 재로딩하는 방식 대신 준비본을 폐기한다.
- [확인] 에디터 통합 시험에서 외형·염색·무기 자세와 배경의 취소/다시 실행, 현재 카메라 유지, 이력 대상 리소스 누락 시 기존 장면·분기 유지, 가져오기 승인 후 이력 삭제를 확인했다. 실제 Ctrl+Z/Y 입력·슬라이더 드래그는 이번 자동 시험 범위에 넣지 않았다.

| 시나리오 | 기대 결과 |
|---|---|
| 옷 A→B, 카메라 회전·3x 선택, Ctrl+Z | 옷만 A로 복원, 회전·3x 유지 |
| 실행 취소 후 카메라 조작, Ctrl+Y | 꾸미기 다시 실행 가능, 현재 카메라 유지 |
| 배경 변경 후 실행 취소 | 이전 배경 복원, 현재 외형·카메라 유지 |
| 패널 여닫기·UI 숨김·메뉴 조작 | 이력 추가·분기 삭제 없음 |
| JSON 가져오기·코디 초기화 성공 | 두 이력 삭제, 이후 꾸미기 편집부터 기록 |
| 가져오기·초기화 취소 또는 실패 | 기존 이력 유지 |
| 앱·경로 변경 재시작 | 작업 복원, 이력은 비어 있음 |
